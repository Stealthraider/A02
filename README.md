# Visual Studio
// 1. The first step to set up visual studio is to download it from the link

// 2. The second step of installing visual studio is to install it onto your machine with the correct settings

// 3. After installation navigate to cloned repository and you will be led to the main **branch** of your repository

// 4. In order to begin to transfer from local to remote repository you need to use the command git add .

// 5. After that to queue the command you must use the command git **commit** -m 

// 6. The final command to transfer the changes is to use the command git **push** origin repository name

// 7. Before and after any git pushes you should use the command git **pull** origin main to synchronize your local and remote repositories 

// 8. Another way to pull changes is to use git **fetch**, it does not affect our current working directory

// 9. There is a posssibility of a **merge conflict** if your local and remote repositories have files that do not match 

// 10. In order to **merge** them you have to fix the differences between the repositires to match up and then use the command git merge
